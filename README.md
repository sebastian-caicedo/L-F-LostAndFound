# L&F (Lost & Found) — Gestión de Objetos Perdidos y Encontrados

Aplicación web para la comunidad universitaria orientada a centralizar el reporte, búsqueda y recuperación de objetos perdidos mediante un mecanismo de verificación por comparación de atributos que previene reclamaciones fraudulentas.

## 📝 Descripción del Proyecto

En el campus universitario, la pérdida de pertenencias personales es cotidiana y suele gestionarse por canales informales (redes sociales, carteleras físicas). Esta informalidad provoca dispersión de la información y falta de trazabilidad. Además, las plataformas existentes suelen publicar abiertamente las imágenes y características distintivas de los objetos encontrados, lo que expone los datos a solicitudes fraudulentas por parte de terceros.

**L&F** resuelve este problema al incorporar una **verificación por comparación de atributos ocultos**: los detalles distintivos entregados por quien reporta un objeto encontrado permanecen protegidos y solo se validan contra la descripción que suministre la persona que intenta reclamarlo.
