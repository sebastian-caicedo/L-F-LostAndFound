# L&F (Lost & Found) — Gestión de Objetos Perdidos y Encontrados

Aplicación web para la comunidad universitaria orientada a centralizar el reporte, búsqueda y recuperación de objetos perdidos mediante un mecanismo de verificación por comparación de atributos que previene reclamaciones fraudulentas[cite: 1].

## 📝 Descripción del Proyecto

En el campus universitario, la pérdida de pertenencias personales es cotidiana y suele gestionarse por canales informales (redes sociales, carteleras físicas)[cite: 1]. Esta informalidad provoca dispersión de la información y falta de trazabilidad[cite: 1]. Además, las plataformas existentes suelen publicar abiertamente las imágenes y características distintivas de los objetos encontrados, lo que expone los datos a solicitudes fraudulentas por parte de terceros[cite: 1].

**L&F** resuelve este problema al incorporar una **verificación por comparación de atributos ocultos**[cite: 1]: los detalles distintivos entregados por quien reporta un objeto encontrado permanecen protegidos y solo se validan contra la descripción que suministre la persona que intenta reclamarlo[cite: 1].
